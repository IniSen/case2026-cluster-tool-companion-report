# CASE2026 Cluster Tool Companion Report

This repository publishes the companion report PDF for the conference paper:

**Clean-Aware CP- and Data-Guided LNS for Semiconductor Cluster Tool Scheduling under JIT Time-Lag Constraints**

The report is an extended technical companion that documents the modeling layers, CP-guided LNS implementation, event-level validation, and supplementary computational analyses.
